# Noordin Network Demo

Capstone demo (PROJ2999, GITAM): explainable imitation learning on real covert networks:
- **Noordin Top** (real Jakarta 2009 terror cell)
- **Caviar** (real drug trafficking network from police phone intercepts)
- **Drugnet** (real acquaintance network among drug users)
- **Knecht** (real friendship network in a school class)

### Disclaimer
*Network structure is real; all agent traits, actions and rewards are simulated and make no claim about real individuals.*
